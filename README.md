1. Qual a importância do Git para desenvolvimento de software?
R: O Git é extremamente imporante para a criação de software colaborativo, e isso se amplia ainda mais em softwares de código aberto ou software livre, plataformas como github e gitlab ampliam ainda mais a colaboração, com Pull Requests, e forks mais simples.
2. Como o uso de branches pode ajudar no trabalho em equipe?
R: O uso de branches pode ajudar no trabalho em equipe por que assim um dos colaboradores pode falar "quero colocar um recurso mas nao sei se vai dar certo", aí ele cria uma branch e testa, enquanto o código original fica intacto.
3. Por que é importante escrever mensagens de commit claras?
R: E importante por que assim futuros colaboradores e outras pessoas podem entender exatamente não só o que foi feito, mas o por quê daquilo.
4. Quando você usaria o arquivo .gitignore?
R: para colocar arquivos descartáveis que NAO devem ser incluídos no projeto final.
